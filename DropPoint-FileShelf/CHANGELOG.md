# Changelog

## 0.1.0

- Reworked the DropPoint window into an always-on-top desktop file shelf.
- Rendered each dropped file or folder as an independent card.
- Added single-card drag-out without removing the item from the shelf.
- Added image thumbnails, file-type icons, individual removal and clear-all.
- Updated the application identity and Windows artifact names.
- Upgraded the Electron runtime and modernized the preload file-path bridge.
- Added Playwright tests for launch, cards, native drag payloads and clean shutdown.
