# taobao1111 项目规则

- 每次修改完成并通过相关验证后，自动提交 Git 并推送到已确认的 GitHub 发布仓库，无需再次询问是否同步。
- 推送前必须检查实际发布文件、暂存差异和全部待推送提交，完成脱敏；真实配置、私密链接、密钥、设备信息、日志和运行截图保留在本机。
- 只提交本次任务相关改动，保留其他未提交修改。存在未解决的脱敏问题、验证失败或远程冲突时，停止推送并报告原因；不得强推或覆盖他人修改。
- GitHub 同步范围仅限本独立项目的源码、文档和构建脚本。供观众运行的成品 ZIP 仅用于个人网站分发，不上传 GitHub Release。
- 推送后核对远程提交编号，并向用户报告同步结果；不能只完成本地提交就声称已同步。
