# 淘金币双11能量 · 本地运行版

给 Windows 10/11 64 位电脑使用的独立管家窗口。OCR 在自己的电脑上运行，模型随程序附带，不上传手机截图，不需要腾讯云服务、API Key 或 ENV 配置。

## 两种分发版本

- **GitHub 源码版**：本仓库 taobao1111/ 包含任务脚本、独立管家窗口、依赖声明和构建脚本，供查看、修改和自行构建。GitHub 自动生成的 Source code 压缩包也是源码版，需要按下方开发说明安装依赖后运行。
- **个人网站成品版**：taobao1111-v0.3.0-windows-x64.zip 仅放在作者个人网站供观众下载，解压后直接运行。成品 ZIP 不上传 GitHub Releases，也不提交到 Git 仓库。

## 观众使用步骤

1. 从作者个人网站下载 taobao1111-v0.3.0-windows-x64.zip。网站下载地址以作者公布的地址为准。
2. 将整个压缩包解压到普通文件夹，双击 `taobao1111.exe`。不要只取出 EXE；旁边的 `_internal` 文件夹也需要保留。
3. 手机开启开发者选项和 USB 调试，使用数据线连接电脑，在手机上允许调试。也可以打开无线调试，用管家的“连接手机”页面扫码配对；无线连接时手机和电脑须在同一网络。
4. 手机自行登录淘宝，打开淘宝首页，在窗口中点击“启动”。窗口不会自动开始任务。
5. 查看实时日志；需要结束时点击“停止”。关闭窗口也会停止本窗口启动的任务。

发布版自带 Python 运行环境、本地 OCR 模型和 adb，不需要安装 Python、uv 或单独部署 OCR。首次使用手机时可能需要在手机上确认安装/启动自动化服务。部分手机的 USB 驱动需要使用手机厂商提供的驱动；不便安装驱动时可以用无线调试。

窗口使用 Windows 的 WebView2 组件。Windows 未提供该组件时，按启动提示安装 Microsoft WebView2 Runtime 后再打开。

## 任务规则与数据

- 淘宝内任务优先，其次支付宝，最后其他应用。
- 缺少目标应用或进入下载安装页时直接返回，不主动下载。
- 跳过升级赛车、小游戏、天猫积分兑换、拍立淘、邀请、预约提醒和消费操作。
- 使用 U2 控制手机；页面无可读文本时使用本地 RapidOCR。每次运行默认最多60分钟；活动页面变化时可能需要更新脚本。
- 手机账号登录在手机上完成，程序不要求填写淘宝或支付宝密码。
- 打包版的日志与最近识别截图保存在 `%LOCALAPPDATA%\taobao1111\` 下，仅供自己排查。不要将整个数据目录公开或转发。
- 旧版云 OCR 配置不再读取。已有配置可以保留在本机，本地识别不需要它。

## 开发与构建

以下命令只供维护者使用，观众无需执行：

```powershell
uv sync --group build
uv run pytest
uv run python app.py
uv run --group build python tools/build_windows.py
```

Windows 发布包从干净、已提交的源代码构建。构建时从 Google 官方下载 adb，收集 Python、RapidOCR 模型和所需库，附带第三方许可文件。`.vendor/`、`build/`、`dist/`、本机配置、日志、截图均不提交。发布前检查实际程序包和提交内容是否包含私密信息。
